# Vinyl Set Builder

Небольшой сервис на FastAPI, который берёт вручную заполненный крейт виниловых треков (BPM,
тональность в нотации Camelot) и строит рекомендованный порядок DJ-сета — последовательность
треков, где каждый переход проверен на совместимость по темпу и тональности.

## Почему выбраны такие структуры данных

- **`list[Track]`** — крейт и итоговый порядок сета оба являются последовательностями, где важен
  порядок (порядок проигрывания треков), поэтому список — естественный выбор.
- **`tuple[float, str]`** — пара `(bpm, key)` трека используется как неизменяемая «координата» для
  сравнения совместимости; кортеж подчёркивает, что эта пара никогда не мутируется на месте.
- **`dict[int, set[int]]`** — граф совместимости сопоставляет id трека *множеству* id треков, в
  которые можно перейти. Множество здесь уместно, потому что порядок соседей не важен, а дублирующиеся
  рёбра бессмысленны — важна только принадлежность, а членство/объединение/пересечение множеств —
  O(1)/O(n).

## Запуск

```bash
make install    # создаёт .venv и ставит пакет вместе с dev-зависимостями
make run        # чистый запуск, крейт пустой
make run-mock   # запуск с уже заполненным крейтом (см. ниже)
```

Откройте `http://localhost:8000/docs` для интерактивного Swagger UI — добавьте несколько треков через
`POST /tracks`, затем вызовите `POST /build-set`, чтобы получить рекомендованный порядок.

`make run-mock` сразу засевает крейт демонстрационным набором современного хип-хопа (Tyler, The
Creator, Post Malone, Kendrick Lamar) — можно сразу вызвать `POST /build-set` и увидеть результат,
не добавляя треки вручную. Набор специально подобран так, что пять треков образуют плавную цепочку
по темпу и тональности, а последний (HUMBLE.) — намеренный «чужак», на нём виден жёсткий обрыв.
